# Курс по структурам данных на C++

Исходный код курса по структурам данных на C++: от стека и очереди до
двоичных деревьев, красно-чёрного дерева, кодировщика Хаффмана и хеш-таблиц.
Каждый урок — небольшая программа с собственной реализацией
структуры данных.

[English version](README.md)

## О репозитории

Здесь лежит код из видеоуроков. Курс ещё в разработке: часть уроков может
быть не завершена, а код написан в первую очередь для наглядного обучения,
а не для промышленного применения.

## Требования

- **Visual Studio 2022 или 2026** с нагрузкой «Разработка классических
  приложений на C++»
- **CMake 3.20 или новее** (для генератора `Visual Studio 18 2026` нужен CMake 4.2+)
- C++20 (в проекте задан `CMAKE_CXX_STANDARD 20`)

Код рассчитан на MSVC (Windows). Сборка под GCC/Clang не поддерживается.

## Сборка

Сгенерировать файлы сборки и собрать все уроки:

```bat
cmake -B build -G "Visual Studio 18 2026"
cmake --build build --config Debug
```

Для Visual Studio 2022 используйте `-G "Visual Studio 17 2022"` с CMake 3.21+;
генератору `Visual Studio 18 2026` требуется CMake 4.2+.

Сборка одного урока по имени таргета:

```bat
cmake --build build --config Debug --target 160_HuffmanTree
```

Исполняемые файлы попадают в `build\Debug\`. Каждый урок — отдельный
executable; статическая библиотека `Misc_gex` содержит общий класс
`gexception` и линкуется в уроки, которые его используют.

## Структура проекта

```
src/
  010_stack_i … 192_unordered_multimap   по папке на урок
  Misc_gexception/   класс исключения gexception (статическая библиотека Misc_gex)
  Misc_sld/          кастомный детектор утечек
  Misc_tests/        общие шаблоны тестов
  Misc_vec/          небольшой динамический массив-помощник
  test/              черновой таргет
CMakeLists.txt       единая конфигурация сборки всех таргетов
```

## Примечания

- Урок про дерево Хаффмана (`160_huffman_tree`) читает из рабочего каталога
  файл `big_data.txt` со списком слов; в репозиторий этот файл не входит —
  положите рядом свой.
- Visual Leak Detector (`src/vld/`) — сторонний инструмент, в репозиторий не
  включён.
